# 防合盖休眠 · 让 MacBook 合上盖子后继续运行

一句话：**合上盖子后，系统不休眠、Wi‑Fi 不断、Tailscale 不离线、RustDesk / ToDesk 远程桌面随时能连进来。**

适用机型：本机 MacBook Air（Apple M4 / macOS 15.7.9），原理对 Intel Mac 同样适用。

---

| 步骤 | 做什么 | 预期结果 |
| --- | --- | --- |
| 1 | 双击 **`1-开启防合盖休眠.command`** | 弹窗输入开机密码 → 显示 ✅ 已开启 |

## 原理（为什么这样就够了）

macOS 的合盖休眠由系统电源管理里的一个开关控制：`pmset disablesleep`。

```
sudo pmset -a disablesleep 1     # 关闭「合盖休眠」
sudo pmset -a disablesleep 0     # 恢复「合盖休眠」
```

打开后，系统不再因为「合盖」进入睡眠。网络接口、Tailscale 后台进程、RustDesk / ToDesk 服务都还在运行，
所以从外网通过 Tailscale IP（本机 `100.91.137.116`）就能连回远程桌面。

这个设置写在 `/Library/Preferences/com.apple.PowerManagement.plist` 里，**重启、关机后仍然有效**。

**为什么不用 `caffeinate`？**
`caffeinate` 只能阻止「闲置休眠」（idle sleep），管不住「合盖休眠」（clamshell sleep）这条路径，合盖后系统照样睡。

**为什么必须要管理员密码？**
这是系统级电源策略，普通用户没有权限修改，所以脚本会调用 macOS 官方的授权弹窗（`osascript ... with administrator privileges`）。
密码只会交给系统弹窗，脚本里没有任何保存密码的逻辑。

## 注意事项

- **耗电**：合盖后系统还在跑，电池供电时大约每小时掉 5%～10%（取决于负载）；插着电就没感觉。
- **发热**：不要把正在合盖运行的 Mac 塞进包里/抽屉里，散热口被堵会明显发热降频。
- **电池健康**：macOS 的充电管理不受影响，无需额外设置。
- **系统升级后**：macOS 大版本升级有可能重置电源策略，升级完运行一次 `3-查看状态.command` 复查即可。
- **想临时恢复休眠**：双击 `2-关闭防合盖休眠.command`；**关机并不会关闭它**，必须运行 2 号脚本。
- **公司电脑**：本机未受 MDM 管理（已确认），改动本地电源策略是纯本机行为。

## 如果合盖后远程桌面看到黑屏

合盖后内屏会关闭，个别远程桌面软件抓到的是「已关闭的内屏」，于是显示黑屏。按顺序排查：

1. **先确认网络与进程都正常**：运行 `3-查看状态.command`，看 Tailscale 是否在线、RustDesk 是否运行。
   再从另一台电脑执行 `tailscale ping 100.91.137.116`，能通就说明网络侧没问题。
2. **看测试报告里的「四、画面」**：`4-合盖测试.command` 会在合盖期间截屏，
   如果截图都小于 100 KB（正常桌面截图约 6 MB），说明画面确实是黑的。
3. **对症处理（按推荐顺序，需实测）**：
   - 换一个远程桌面软件试试：本机同时装了 RustDesk 和 ToDesk，两者抓屏实现不同，表现可能不一样；
   - 接一个 **HDMI / USB‑C「诱骗器」（dummy plug，几十元）**：系统会认为接了外接显示器，
     合盖后外接画面依然存在，远程桌面通常就能看到完整桌面；
   - 或者用 **BetterDisplay** 这类软件创建虚拟显示器（软件方案，需自行安装并实测）；
   - 最后才是外接一台真实显示器。
4. 如果只是「隔着黑屏也能操作」（鼠标键盘可用），也可以先这样用，画面问题再慢慢优化。

> 说明：合盖后的画面能不能抓到，取决于显卡驱动和远程软件的实现，脚本无法 100% 替你确认，
> 最终请从 `yyzwindows11` 用 RustDesk 实际连一次。

## 常见问题

**Q：开机密码会被保存吗？**
不会。密码只输入到 macOS 系统自带的授权弹窗里，脚本只负责调用 `/usr/bin/pmset`。

**Q：能不能只在插电的时候生效？**
`disablesleep` 是全局开关，不区分电源。如果希望「插电才不休眠」，可以拔电前运行 `2-关闭防合盖休眠.command`。

**Q：合盖后会不会自动锁屏？**
会。macOS 默认要求密码解锁，这是**正常且安全**的：远程桌面连上去看到的是锁屏/登录界面，解锁后即可操作（RustDesk / ToDesk 支持发送解锁密码）。

**Q：会不会影响自动更新、Time Machine？**
不会。系统只是不睡，后台任务照常。

**Q：不想要了怎么彻底卸载？**
双击 `2-关闭防合盖休眠.command` 恢复默认，然后把整个「防合盖休眠」文件夹删掉即可，系统里不会残留其他东西。

**Q：为什么 `3-查看状态.command` 里的「macOS 屏幕共享」显示未开启？**
这是系统自带的远程桌面（VNC）。你没有开启它，但你用的是 RustDesk / ToDesk，不影响使用；
要用系统自带的，去「系统设置 → 通用 → 共享 → 屏幕共享」打开即可。
